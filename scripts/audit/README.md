# Текстовый аудит сайта

Конвейер проверки всех текстов hand-marketing.ru: человечность речи, подписи
к кадрам, маркетинговая работа текста, красные флаги для поисковиков.

## Зачем так, а не «дать агенту страницу»

Агенту нельзя показывать HTML: тильдовская разметка и наши кейсы с canvas дают
кашу, в которой не видно текста и не найти, где его править. Поэтому сначала
страница снимается в структурированный дамп, потом механику снимает линтер
без модели, и только оставшееся уходит ревьюерам.

## Шаги

```bash
# 1. Снять текст с живых страниц (playwright, десктоп 1440 + телефон 390)
python3 scripts/audit/extract_text.py --all
python3 scripts/audit/extract_text.py event/changan        # одна страница
python3 scripts/audit/extract_text.py --all --only video/  # префикс

# 2. Линт без модели + сборка брифов для агентов
python3 scripts/audit/lint_text.py
```

Что получается:

| Что | Где | Для кого |
|---|---|---|
| дамп страницы | `pages/<slug>.json` | машина |
| бриф: текст в порядке чтения с номерами F001 | `briefs/<slug>.md` | агенты и человек |
| общие блоки сайта (шапка, подвал, форма) | `briefs/_common.md` | правятся один раз |
| механические находки | `lint.md`, `lint.json` | человек |
| отчёты ревьюеров | `agent-out/<slug>/*.md` | сводит copy-lead |
| итоговый патч-лист | `agent-out/<slug>/patch.md` | по нему правим |

## Ревьюеры

Живут в `.claude/agents/`, вызываются Agent tool. Никто из них не правит файлы:
дизайн и вёрстка остаются одной головой, иначе голос сайта расползётся.

- `copy-humanizer` — ИИ-штампы, канцелярит, тройки, длинное тире
- `caption-critic` — подписи, пересказывающие кадр; немые кадры; alt
- `copy-marketer` — первый экран, доказательная база, путь к заявке
- `seo-auditor` — мета, H1, смысл в графике, переспам, перелинковка, Вордстат
- `copy-lead` — сводит четверых в один патч-лист и снимает противоречия

Порядок: четверо параллельно → `copy-lead` → правки → `case_qa.py`.

## Где править найденное

Бриф всегда называет источник. Для 52 страниц это генератор
`scripts/a2/gen_*.py`, и после правки нужен
`python3 scripts/a2/finalize_page.py gen_<slug>.py`, иначе пост-скрипты
(cookie, цели Метрики) затрутся. Для остальных правка идёт прямо в `mirror/`.

Правка текста меняет его длину и может сломать вёрстку, поэтому после каждой
пачки страниц гоняем `python3 scripts/a2/case_qa.py <путь>`.

## Что линтер считает сам

Мета (длины, дубли по сайту, canonical), H1, объём текста, соотношение
текста и графики, alt, длинное тире, лапки вместо ёлочек, заглавное «Вы»,
двойные пробелы, словарь штампов, подписи с «на фото», серии из 4+ кадров
без слов, переспам одного слова, битые внутренние ссылки.
